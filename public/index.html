Linux OS Volume Mount & Format Procedure

# 1. View attached raw storage devices
lsblk

# 2. Format volume with ext4 file system
sudo mkfs -t ext4 /dev/xvdf

# 3. Create mount target directory
sudo mkdir /mnt/davv_data

# 4. Mount partition to mount point
sudo mount /dev/xvdf /mnt/davv_data

# 5. Persist across reboots in /etc/fstab
echo '/dev/xvdf  /mnt/davv_data  ext4  defaults,nofail  0  2' | sudo tee -a /etc/fstab

# 6. Verify filesystem disk space
df -h /mnt/davv_data

EBS Volume Types Comparison

gp3 (General Purpose SSD)

Baseline 3,000 IOPS & 125 MB/s throughput regardless of volume size.

io2 (Provisioned IOPS SSD)

High performance mission-critical database workloads up to 256,000 IOPS.

st1 (Throughput Optimized HDD)

Low-cost magnetic storage for streaming big data, logs and data warehouses.

AWS VPC (Virtual Private Cloud) & Site-to-Site VPN

CIDR: 10.0.0.0/16

Subnet Topology & Routing Table

VPC & VPN Provisioning Script

# 1. Create VPC with 10.0.0.0/16 CIDR
VPC_ID=$(aws ec2 create-vpc --cidr-block 10.0.0.0/16 --query 'Vpc.VpcId' --output text)

# 2. Attach Internet Gateway (IGW) for Public Subnet
IGW_ID=$(aws ec2 create-internet-gateway --query 'InternetGateway.InternetGatewayId' --output text)
aws ec2 attach-internet-gateway --vpc-id $VPC_ID --internet-gateway-id $IGW_ID

# 3. Create Public Route Table (0.0.0.0/0 -> IGW)
RT_PUB=$(aws ec2 create-route-table --vpc-id $VPC_ID --query 'RouteTable.RouteTableId' --output text)
aws ec2 create-route --route-table-id $RT_PUB --destination-cidr-block 0.0.0.0/0 --gateway-id $IGW_ID

# 4. VPN Connection Status
aws ec2 describe-vpn-connections --query 'VpnConnections[0].VgwTelemetry'
